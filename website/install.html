Install

Get it running on your MacBook

  1. Download MacClipboard.zip and unzip it.
  2. Drag MacClipboard.app into Applications.
  3. Open it. If macOS says it could not verify the app, click Done, not Move to Trash.
  4. System Settings → Privacy & Security → Open Anyway.
  5. Enable Accessibility so Enter can paste into the previous app.

Terminal, after the app is in Applications:

xattr -cr /Applications/MacClipboard.app && open /Applications/MacClipboard.app

Default shortcut is ⌃⌥V. Requires macOS 14+ on Apple Silicon.
