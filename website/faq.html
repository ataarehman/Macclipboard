FAQ

Frequently asked questions

Everything you need to know about MacClipboard. Can’t find an answer? Open an issue on GitHub.

How do I open clipboard history?

Copy as usual with ⌘C, then press ⌃⌥V. Use the arrow keys and Enter to paste into the app you were using. Change the shortcut in Settings → Keyboard.

macOS says the app can’t be opened

This build is ad-hoc signed, so Gatekeeper may block it. Click Done, then System Settings → Privacy & Security → Open Anyway. Or run:

xattr -cr /Applications/MacClipboard.app

Full steps are on the install page.

Why does it ask for Accessibility?

Automatic paste needs Accessibility so MacClipboard can return to the previous app and send ⌘V. History, search, and pin still work if you decline — you would then paste with ⌘V yourself.

Does my clipboard leave this Mac?

No. There are no accounts, analytics, or cloud sync. History lives at ~/Library/Application Support/MacClipboard. See Privacy.

Can I hide password copies?

Add password managers and banking apps to excluded applications, pause monitoring, or clear history. Transient and concealed pasteboard markers are skipped when other apps set them.

Does it run on Intel Macs?

No. This build is Apple Silicon only (M1 and later) on macOS 14+.

How do I move the menu bar icon?

Hold ⌘, then drag the MacClipboard icon to a new place in the menu bar.
