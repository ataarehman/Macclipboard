v1.0.0

August 25, 2026

First public release of MacClipboard — Windows + V clipboard history, native on MacBook.

  • Menu-bar clipboard history for text, URLs, images, and files
  • Default shortcut ⌃⌥V, with an in-app recorder
  • Enter pastes into the app you were using
  • Pin, search, delete, exclusions, and pause monitoring
  • 100% local storage — no analytics or cloud sync
